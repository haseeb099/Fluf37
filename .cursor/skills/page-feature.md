# Workflow
1. Review the target page requirements.
2. Find similar pages and components.
3. Create the UI structure.
4. Wire state and data fetching.
5. Add loading, empty, and error states.
6. Match the design system.

# Rules
- Use reusable components.
- Prefer composition over duplication.
- Keep styling consistent.
- Validate incoming data before rendering.
